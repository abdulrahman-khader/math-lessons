# دروس الرياضيات التفاعلية

عروض تفاعلية للسبورة الذكية لدروس الرياضيات في المرحلة الابتدائية. لكل درس ملف HTML واحد يعمل دون إنترنت.

## الاستعمال في الصف

الدروس منشورة على: https://abdulrahman-khader.github.io/math-lessons/
تُحدَّث تلقائيًا عند كل دفع إلى main بعد نجاح الاختبارات. للعمل دون إنترنت احفظ صفحة الدرس (Ctrl+S): كل درس ملف واحد.

أو ابنِ الدروس بـ `npm run build`، ثم افتح ملف الدرس من مجلد `dist/` في المتصفح (Chrome أو Edge) واضغط F لملء الشاشة. الملف مستقل: انسخه إلى أي جهاز أو ذاكرة USB.

| المفتاح | العمل |
| --- | --- |
| ← | الشريحة التالية |
| → | الشريحة السابقة |
| المسافة | الخطوة التالية من الحل |
| R | إعادة الشريحة: تمحو الحل والإجابات والسحب ورسم القلم فيها |
| F | ملء الشاشة |
| Home | الصفحة الرئيسية |

في الرأس: إعادة الشريحة، والقلم، والمؤقت، وعجلة الأسماء، ونجم الأسبوع، ووضع المعلم (يُظهر ملاحظات كل شريحة)، وكتم الصوت.

**نجم الأسبوع:** لطلاب الفصل المختار في الصفحة الأولى من الدرس. لكل طالب نجمة ⭐ (+١) وغلطة ✖ (−١)، والمجموع = النجوم − الأغلاط ويراه الطلاب. تُعطى من لوحة «النجوم»، أو تحت الاسم الذي يخرج من العجلة، أو من الجوال. الأسبوع من الخميس إلى الأربعاء، وكل خميس تُفتح اللوحة على منصة أفضل خمسة في الأسبوع الذي انتهى (عند التساوي يتقدّم الأقل أغلاطًا). النجوم مشتركة بين كل الدروس ومحفوظة في متصفح الجهاز.
يحفظ المتصفح نقاط الفرق وآخر شريحة، فتظهر «متابعة من الشريحة…» في الحصة التالية.

## للتطوير

يتطلب Node.js 20 أو أحدث، وGoogle Chrome لتشغيل الاختبارات.

```bash
npm install
npm run dev -- 3-4     # خادم تطوير لدرس واحد
npm test               # فحص الأنواع، فحص RTL، البناء، الاختبارات
npm run shots -- 3-4   # صور لكل الشرائح في shots/
```

القواعد وطريقة كتابة درس جديد في `CLAUDE.md`.
